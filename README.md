# iLikePDF

> **Simple, fast and private online PDF & image tools — right in your browser.**

iLikePDF is a lightweight, frontend-only web app that gives users six essential
file tools for everyday PDF and image work. No installs, no sign-up, no watermarks.

🌐 **Live:** [https://ilikepdf-dpl.pages.dev](https://ilikepdf-dpl.pages.dev)

---

## ✨ Features

- **6 essential tools** — compress, convert, merge and shrink PDFs and images
- **Zero sign-up** — use every core tool without creating an account
- **Privacy-first** — files are encrypted in transit and removed after 2 hours
- **Fast by default** — most files process in under 10 seconds
- **Fully responsive** — optimized for mobile, tablet and desktop
- **Clean UI** — paper-toned, minimal design with accessible contrast

---

## 🧰 Tools Included

| Tool | What it does |
|------|--------------|
| **PDF Compressor** | Reduce PDF file size with light, balanced or strong compression — including a precise **100 KB target**. |
| **JPG to PDF** | Convert JPG, PNG, HEIC and other images into a single, neatly ordered PDF. |
| **PDF to Word** | Convert PDF files into editable Word documents while keeping the layout. |
| **Word to PDF** | Turn DOC and DOCX files into clean, shareable PDFs in one step. |
| **Merge PDF** | Combine multiple PDF files into one and arrange page order. |
| **Photo Compressor** | Reduce image/photo file size while maintaining good quality. |
